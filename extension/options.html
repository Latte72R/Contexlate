翻訳の設定

Contexlate

翻訳 API に接続して、お好みの言語でページを読みます。

https://llm.keioaic.dev/v1 まで入力してください。接続先を変更すると Chrome がアクセス許可を求めます。 KEIOAIC_LLM_API_KEY の値を入力します。このブラウザー内に保存し、Chrome の同期には送りません。 既定は 8。複数タブと選択文翻訳を合わせた上限です。サーバーの処理能力に合わせて指定してください。

訳文をこのブラウザー内に最大200件・2 MiB保存します。接続テストはキャッシュを使いません。

翻訳したいページで拡張アイコンを押すと、そのページのテキストを API に送信します。選択文翻訳では選択した文字だけを送信します。入力中のフォーム値、パスワード、コードブロックはページ翻訳の対象外です。API キーは暗号化された保管庫ではなく、拡張専用ストレージに保存されます。
