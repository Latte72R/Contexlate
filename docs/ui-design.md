# UIの調整

## 方針

- 用途：外国語のページをその場で読むための翻訳ツール。
- 性格：落ち着いた、読み取りやすい、実務的。
- 素材感：紙面とインク。既存の淡い背景・深緑・ロゴを維持。
- 強調：選択した翻訳モード、主操作、翻訳結果。
- 共通の目印：「行」を表したロゴと、訳文の左端を揃える配置。

## 調整内容

元の画面は配色やロゴを活かせる状態だったため、全面的に作り直さず、以下を調整しました。

- 余白：4px単位に整理し、入力欄・ボタンの高さと項目間の間隔を統一。
- 色：従来の深緑と淡い背景を維持。本文・補足・主操作の色を整理。
- アイコン：既存のロゴを維持。装飾用のアイコンは追加しない。
- 文言：設定の補足を短くし、API接続と翻訳表示を分けて案内。
- 文字：ローカルフォントを利用し、見出しの太さと文字間隔を調整。技術的な入力値は等幅で表示。
- 配置：モデル名と並列数、翻訳先と表示方法を並べ、狭い画面では縦に表示。
- 操作：ホバーとキーボードフォーカスを明示。補足説明を入力欄のaria-describedbyに関連付け。
- 表示：選択文の訳文に深緑の左罫線を付ける。著作権とMITライセンスへのリンクを拡張画面とページ上のパネルに表示。
- 動き：短い色の変化だけを使い、動きを減らす設定では無効にする。

画像生成・外部フォント・追加ライブラリは使っていません。

調整には Damir Sokolovsky（[@heydamir](https://x.com/heydamir)）作の [unslop](https://heydamir.design/unslop) スキル（CC BY 4.0）を使用しました。スキルのコードや画像は製品に同梱していません。


## 再調整

ロゴ・深緑・淡い背景と、本文16px・補足14pxの読みやすさを維持した調整です。

- 設定画面の「ロゴとContexlate → 翻訳の設定 → 設定項目」という階層を保ち、ページ見出しを28px、項目グループの見出しを18pxに調整。
- 入力グループ内の間隔を16px、グループ間を24pxに揃え、補足文は画面幅で自然に折り返す。
- APIベースURLが空欄であることは保ち、入力例をプレースホルダーで案内。
- 選択文画面の余白を抑え、翻訳完了後は「訳文をコピー」を主操作にする。再翻訳中・中止後は「翻訳する」を主操作に戻す。
- ポップアップの横幅400px、著作権者Latte72、ユーザー提供のSVGロゴを維持。
